### A) Funciones demostradas

El video demuestra las siguientes funciones y componentes de la interfaz de Cloudflare API Shield (dentro de la sección "Security" > "Web assets"):

*   **Discovery (Descubrimiento mediante Machine Learning):** Identifica automáticamente todos los puntos finales (endpoints) de la API activos. Los endpoints descubiertos se pueden guardar en "Endpoint management".
*   **Endpoint Management (Gestión de endpoints):** Un inventario de los endpoints guardados donde se centraliza la información de rendimiento, límites de tasa recomendados y etiquetas de riesgo.
*   **Schema validation (Validación de esquema):** Permite implementar un **"positive security model"** (modelo de seguridad positivo) donde se aplica un esquema aprendido automáticamente o modificado por el cliente. Bloquea el tráfico que no cumple con el esquema (métodos, parámetros o endpoints no permitidos), resolviendo el problema de **"dangling and zombie APIs"** (APIs zombis y colgantes). Permite exportar el esquema en formato OpenAPI v3.
*   **Sequences (Secuencias):** Analiza cómo los usuarios interactúan con la API rastreando el orden de las solicitudes. Muestra métricas como "Correlation score", "Length" y "Frequency".
*   **API sequence rules (Reglas de secuencia de API):** Dentro de "Security rules", permite crear reglas de mitigación que imponen un orden estricto en el que deben llamarse las APIs (por ejemplo, requerir un GET a `/balance` antes de permitir un POST a `/transfer`).
*   **Volumetric abuse protection (Protección contra abuso volumétrico):** Cloudflare mantiene una línea base (baseline) del tráfico de cada endpoint y sugiere un **"Recommended rate limit per 10 min"** (Límite de tasa recomendado por 10 minutos). Permite crear reglas de limitación de tasa con un solo clic basadas en esta sugerencia.
*   **Labels (Etiquetas):** El sistema aplica etiquetas para categorizar endpoints. Incluye etiquetas definidas por el usuario y etiquetas de riesgo (Risk labels) aplicadas automáticamente por Cloudflare (ej. `pii-risk-sensitive`, `pii-risk-missing-auth`, `pii-risk-mixed-auth`, `pii-risk-missing-schema`).
